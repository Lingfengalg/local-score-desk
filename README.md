# 本地记录工作台

一个自己使用、也方便分享的小工具。浏览器打开即可整理名单、登记成绩和活动、核对并导出结果，无需安装办公软件或搭建后台。

## 开始使用

1. 点击仓库右上方 **Code → Download ZIP**，解压。
2. 双击 **index.html**，用 Edge 或 Chrome 普通窗口打开。
3. 按 **导入名单 → 数据录入 → 老师核对 → 导出结果** 操作。

可先载入示例试用；示例学生均为虚构。简明图解见 [操作图解](docs/quick-start.html)（下载后打开）。

## 主要功能

- 名单导入、成绩表格录入、Excel 文本粘贴和批量活动登记。
- 内置完整量化项目、选项、人数系数、上限及自动计算；空奖项显示待填写。
- 老师集中核对；学生核对单独可选，不是必做步骤。
- 自动保存、立即保存、完整 JSON 备份、恢复、撤销和操作记录。
- 支持最多 500 人，提供轻量动效及减少动态效果支持。
- 可选 AI 辅助及 MCP 工具服务，AI 只提交草稿，最终由页面人工确认。

数据保存在当前浏览器，不会上传 GitHub。不同路径、浏览器或电脑不自动共享数据；换设备、更新文件或清理浏览器前，请先下载完整 JSON 备份。仓库不含真实学生资料、原始参考文件、个人备份或密钥。内置规则是当前版本的计算参考，可在界面确认适用设置，不代表任何机构正式发布。

## 源代码

已提供可直接使用的 `index.html`。修改源代码后需安装 Node.js 22+：

```sh
npm run build
npm test
```

构建和核心测试无第三方依赖。可选浏览器测试需安装 Playwright：`npm install --no-save playwright`，然后安装 Chromium（`npx playwright install chromium`），运行 `npm run test:browser`；也可通过 `BROWSER_CHANNEL=msedge` 使用已安装 Edge。

| 目录 | 内容 |
| --- | --- |
| index.html | 可直接双击使用的完整应用 |
| src/ | 页面、评分引擎、89 个量化项目、虚构示例和工具协议 |
| mcp/ | 无外部依赖的 MCP stdio 服务和配置生成器 |
| docs/ | 简明操作说明和 AI 接入说明 |
| tests/ | 核心计分、MCP 和浏览器回归测试 |

AI 接入方法见 [AI / MCP 说明](docs/ai-mcp.md)。通常不需要启动它。
