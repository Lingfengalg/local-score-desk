# v1.6.0：录入与核对改进

## 直接使用
下载仓库 ZIP，解压后打开 `index.html`。旧页面先下载完整 JSON 备份，再使用新版；不同路径和浏览器不会自动迁移数据。

日常仍然只有三个入口：**班级总览 → 数据录入 → 老师核对**。

## 本轮变化
- 排序不再改变原始名单或数据版本，增加学号排序和恢复原顺序。
- 搜索能定位被“仅看已填写”隐藏的项目；无结果有恢复提示；切换学生同步左侧分页。
- 奖项缺事项名就地提示，重复事项可以定位对方记录；处分区间与百分比显示更明确。
- 任职填写中途不再报红，任期仍需明确选择；资格勾选不再重建整页。
- 成绩表 Enter 跨页、方向键换行、十列评议同屏；直接粘贴多行数据先预览并确认对齐。
- 多人登记可以搜索并勾选姓名；表头识别及匹配姓名的无表头导入更方便。
- 本次会话暂存未提交的批量表单；自动预检不代替最后确认。
- 批次历史就地可见，更正采用明确替换并保留历史；奖项可迁移到兼容项目，之后待审核。
- 可显式连续录入同一项目，查看个人跨维度已填项目汇总。
- 从核对列表处理个人问题后，可以返回原列表；新增批量老师核对，仅限已就绪学生并需人工确认。
- 操作人姓名作为本机偏好记住，不改变计分配置或使其他学生核对失效。
- 核对页可直接导出；导出可选范围与排序，新增含普通项目的完整台账；打印可选范围。
- AI 按钮收拢，草稿应用后可继续人工审核；MCP 临时故障有限重试，不自动重放变更。
- 保存明确标注本电脑浏览器；增加读取成功后的写入探测、撤销估算容量限制及 CSV 防护回归。

## 检查记录
本地开发回归 289 项通过；新增交互检查 42 项，新增 MCP 临时 503 恢复检查 1 项。另有 6 项便携包验证。公开仓库提供可独立运行的核心、MCP、浏览器、动效及交互测试；本地完整回归清单见执行清单。

未修改量化分值和公式，保留原 JSON 格式。任职半填写状态调整为待完善，完整有效记录的计分保持不变。模型接口使用兼容响应模拟测试，未调用真实付费模型。

XLSX 导出、独立内存运行模式和撤销 Diff 重构不包含在此版本中，避免将新的依赖和恢复机制混进本轮修复。具体取舍见 [执行清单](execution-checklist.md)。
