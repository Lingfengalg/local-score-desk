日常只用这三步

一般由老师核对即可，不需要先登记学生核对。

班级总览数据录入老师核对
1

把学生名单导进来

班级总览→名单管理→从 Excel 导入 / 更新

复制“学号、姓名、班级”三列，粘贴后先检查，再确认导入。少量补人可选“添加一名学生”。

同一学号更新姓名和班级，原成绩与活动不会清空。

2

成绩和活动在同一处录入

数据录入→成绩表或活动与奖项

成绩表：直接逐格填，按 Enter 到下一人；已有 Excel 成绩时，点“从 Excel 粘贴成绩”。两种方式更新同一份数据，不用再录一遍。

活动与奖项：左侧选学生，下方选项目、等级和次数。多人参加同一事项，用右侧“多人活动登记”或“多人奖项登记”。

没参加的项目不用填；真实 0 分填 0，缺失成绩留空。

3

老师核对，再导出结果

老师核对→去处理→确认老师已核对

按提示补成绩、核对奖项材料和资格。处理完成后，填写核对老师并确认即可。

在“老师核对”或“班级总览”点“导出结果”，可导出全部试算，或仅导出老师已核对的学生。

学生核对不是必做步骤。
确有需要时，在“其他功能 → 学生核对（可选）”单独登记。没登记或原记录失效，都不会阻挡老师核对和导出。

保存：改动会自动保存在当前浏览器，Ctrl+S 可立即保存。换电脑或清理浏览器前，在顶部“数据与备份”下载完整 JSON；恢复也在同一处。

检查问题：在“数据与备份 → 检查全体数据”搜索、分类和翻页，点“去处理”到对应学生与项目。

改错了：点“撤销”；误撤销可点“重做”。点“撤销记录”可先查看操作。修改成绩、奖项或规则后，需要老师重新核对。

其他功能：新建班级、规则设置、操作记录和可选学生核对集中放在这里。AI 功能仍在“AI / MCP”，不用时可以完全离线。

更新旧版：原页面先下载完整 JSON 备份，再在新版页面导入。不同文件路径和浏览器不会自动共享数据。
