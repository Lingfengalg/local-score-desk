# v1.6.1 优化执行清单

日期：2026-10-20。范围：检查、导出、弹窗和恢复安全；计分规则不变。

## 执行顺序与结果

- [x] 01 全体数据检查：支持班级/搜索范围、问题类型与关键词筛选；每页 40 条，全部问题均可翻页，不再截断在前 40 条。检查窗口加宽，表格区域限高。
- [x] 02 检查结果定位：按记录进入准确学生和观测点，成绩、资格及规则分别进入对应操作页；导出包含全部筛选问题，不只当前页。
- [x] 03 导出范围提示：实时显示所选人数、可试算人数、已核对人数、无总分人数；明确“当前范围”是班级与搜索范围；没有已核对记录时禁用该导出按钮。
- [x] 04 旧预览失效保护：单人核对、学生编辑、规则设置、删除、新建、完整备份恢复在确认时重查工作区与 serial；涉及单人时同时绑定原学生。检查与导出窗口在数据变化后提示重新检查并禁用旧操作。
- [x] 05 异步文件读取保护：CSV 只写入仍打开且相同的导入窗口；JSON 读取期间页面/数据变动或关闭原窗口则取消，不打开过期恢复确认。
- [x] 06 恢复故障保护：清理临时草稿失败时不清空 pendingRecovery，不关闭弹窗；保留下载、恢复入口，错误就地显示。关闭弹窗后可从顶部提示重开；选择前暂停录入，避免与旧草稿混合。
- [x] 07 键盘与生命周期：弹窗有可访问标题，打开时聚焦标题；错误可聚焦并在弹窗内就近显示；取消旧预检定时器，检查窗口替换/关闭时清理搜索定时器。
- [x] 08 回归与交付：新增 22 项检查，重新验证核心计分、录入、存储、AI/MCP、动效、500 人、320px 布局、旧备份及离线能力；同步本地 HTML、公开源码、完整源码包与分发包。

## 验收结果

- 功能检查：311 项（原 289 项 + 新增 22 项）；分发检查另 6 项。
- 新增测试涵盖：95 人跨页、筛选全量导出、准确定位、检查快照过期、导出人数与按钮、单人/规则/删除/恢复旧预览、延迟 CSV/JSON、草稿清理故障、500 人 1000 条问题、弹窗键盘与移动布局。
- 使用独立浏览器上下文与虚构学生；不读取、不刷新用户正在使用的真实工作区。
- 规则 JSON、分值、上限、权重默认值、老师核对要求和 AI 人工确认边界不变。

## 本轮边界

- “检查通过”不等于材料真实或正式归档；搜索没有匹配问题，不代表其他范围没有问题。
- 快照失效保护采取保守策略：即使只是其他学生变化，也要求重新打开相关确认窗口。
- CSV 不具备文本单元格类型，导入 Excel/WPS 请把学号列设为文本。XLSX、完整内存运行模式、撤销 Diff 重构继续作为独立迭代，不宣称已完成。
- 未进行旧 WPS、所有隐私模式、真实断电的全矩阵实机测试；自动化通过不是所有环境的性能保证。

## 使用

先在旧页面下载完整 JSON 备份，再点“立即保存”。原路径刷新后显示 v1.6.1；换路径或电脑时用 JSON 恢复。HTML 文件本身不包含当前学生数据。
